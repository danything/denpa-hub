# 実況のコメントの投稿の決まり

denpa-hub に書く実況のコメント (denpa のライブの画面の書き込みの欄から書くもの。[jikkyo.md](jikkyo.md)) の決まりです。
denpa-hub は Doa が動かしています。

## 書いたものの扱い

- **書いたものは公開されます。** denpa-hub を使うほかの家の画面に流れ、NX-Jikkyo (tsukumijima さんが運営する非公式の実況サービス) にも書かれます。
  NX-Jikkyo に書かれたものは NX-Jikkyo とニコニコ実況 過去ログ API に残り、誰でも読めます
- 書いた人は、書いたものを自分で消せません
- denpa-hub は書いたものを 30 日持ち、過ぎたら消します。NX-Jikkyo と過去ログ API に残ったものは、denpa-hub からは消せません
- denpa-hub は書いた人の接続元のアドレス (IP) を残しません。残すのは本文・時刻・局と、家ごと・人ごとの ID (中身からは誰かを辿れないもの) です

## 書いてはいけないもの

- 法令に反するもの、犯罪を勧めるもの
- ほかの人の権利を損なうもの (著作権・商標権・名誉・プライバシーなど)
- 人を傷つける・脅す・差別するもの
- わいせつなもの、残虐なもの
- 住所・電話番号・メールアドレスなど、人を特定できる情報
- 宣伝・勧誘・スパム、同じものをくり返し書くこと
- ほかの人や団体になりすますもの
- NX-Jikkyo の決まりに反するもの

## 運営者がすること

- 決まりに反する書き込みを、予告なく消すことがあります (denpa-hub の上から。NX-Jikkyo の写しは NX-Jikkyo の運営者に頼んでください)
- 決まりに反する書き込みを続ける家や人の書き込みを、止めることがあります
- 含むコメントを断る語 (NG ワード) を置くことがあります。NX-Jikkyo から受けて配るコメントにも効きます

## 削除の依頼・問い合わせ

次のどちらかで受けます。依頼には、局・時刻 (分まで)・本文を書いてください。

- メール: info@doany.io
- GitHub の Issue: [danything/denpa-hub](https://github.com/danything/denpa-hub/issues)。Issue は誰でも読めるので、個人の情報を含む依頼はメールで送ってください

依頼を受けたら、書き込みを調べ (`denpa-hub comments`)、決まりに反するものは消します。
